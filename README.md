# 雲端圖資同步工具（Google Drive 手動同步）

按「立即同步」即可將指定 Google Drive 資料夾的新增或更新檔案下載到本機，並記錄更新日誌。另提供 DWG 圖面變更比對，可自行選取舊版與新版，以紅色標示刪除、綠色標示新增。

---

## 🚀 安裝（給使用者 / 工地工程師）

1. 到本專案的 [Releases](../../releases/latest) 頁面，下載最新的 `CloudDrawingSync-x.y.z.msi`
2. 點兩下安裝（**不需要系統管理員權限**，裝到使用者自己的帳號下）
3. 桌面與開始功能表會出現「雲端圖資同步工具」捷徑
4. 第一次開啟：按「登入 Google」完成授權 → 在「同步資料夾」按「➕ 新增」
   貼上雲端資料夾連結、選本機資料夾 → 按「立即同步」
5. **可新增多個同步資料夾**（例如不同案場各一組），同步時會依序處理；
   暫時不需要的資料夾可「啟用/停用」切換，不必移除

- 程式**每次啟動會自動檢查新版本**，偵測到新版會詢問是否更新，按「是」即自動下載、安裝、重啟，設定與登入都會保留。
- 設定 / 登入 / 同步狀態存放於 `%APPDATA%\雲端圖資同步工具`，升級與解除安裝都不會動到。

## 📦 發版 SOP（維護者）

1. 改 `drive_sync_gui.py` 開頭的 `APP_VERSION = 'x.y.z'`（版本號唯一來源）
2. 執行 `powershell -ExecutionPolicy Bypass -File installer\build_msi.ps1`
3. `gh release create vx.y.z "dist\CloudDrawingSync-x.y.z.msi" --title "vx.y.z" --notes "更新內容"`
4. 完成——所有安裝戶下次開程式就會收到更新提示

> ⚠️ `credentials.json`（OAuth 憑證）、`token.json` 等機密檔已在 `.gitignore` 排除，**建置 MSI 時需在本機專案目錄放置 `credentials.json`**（見下方 Google Cloud 設定教學）。

## 功能特色

- ✅ 手動一鍵同步多組 Google Drive 資料夾
- ✅ 同步時偵測新增/更新的檔案並下載
- ✅ 啟動時檢查程式新版本
- ✅ 將更新記錄寫入 `update_log.txt`

### GUI 版本（drive_sync_gui.py / 雲端圖資同步工具_新版.exe）

- ✅ 「**今日更新**」摘要可一鍵複製貼到 LINE，**關閉程式後重開仍會保留當天內容**
- ✅ 「**今日更新**」檔名可左鍵直接開啟；右鍵選單可在檔案總管開啟所在資料夾並選取檔案
- ✅ 「**未同步檔案**」頁籤：列出覆蓋失敗的檔案、原因與時間，按「🔁 重試全部」只重新下載失敗的檔案；確定不要追蹤的項目可「移除選取」
- ✅ 「**更新紀錄**」頁籤：依日期展開的歷史紀錄，可查看幾月幾號新增/更新/失敗各幾個檔案、每次同步的明細
- ✅ 以上紀錄存於 `%APPDATA%\雲端圖資同步工具\sync_history.json`（自動產生，最多保留最近 400 次同步）

### DWG 版次比較（v1.2.6）

1. 按「DWG 版次比較」，選擇舊版與新版 `.dwg`，再產生預覽。不必先同步，也可比較同步資料夾以外的檔案。
2. 「今日更新」的 DWG 檔名右鍵選單也可開啟比較視窗，預先帶入新版檔案。
3. 預設「差異疊圖」：**紅色＝舊版才有的線條（刪除）**，**綠色＝新版才有的線條（新增）**，灰色＝未變更。
4. 圖上標出差異編號框，右側列出視覺差異區域，點選或按「上一處／下一處」可放大定位；也可切換「左右滑桿」、「舊版原圖」、「新版原圖」。
5. 滾輪以游標為中心平滑縮放、拖曳平移、雙擊回全圖。操作時立即移動／縮放快取畫面，背景再從向量出圖補繪清晰畫面，不必等差異計算完成才移動。
6. 靜止畫面使用 2 倍取樣再抗鋸齒縮回顯示尺寸，改善斜線、弧線與小字。繪製取樣超過 800 萬像素的大視窗會改以原生尺寸繪製以限制記憶體；快速操作中的暫時快取畫面不代表最終清晰度。
7. v1.2.3 使用固定圖面座標的分塊快取：平移只補新露出的區域，同一比例回訪可重用；只繪製目前模式需要的圖層。快取像素緩衝上限為 96 MiB（不含來源圖面與工作緩衝），交換／更換圖檔即建立獨立快取。
8. 縮放動畫會立即投影現有畫面，並提前在背景繪製目標倍率，不必等動畫結束才開始補圖。新畫面先顯示原生解析度的向量文字及線條，再於停止操作約 140 ms 後排程 2 倍抗鋸齒補繪；拖曳沿用已有的高品質圖塊。新操作可取消尚未完成的高品質工作。首次載入或未快取的縮放比例仍須繪製，不保證所有操作耗時相同。
9. v1.2.4 取消固定 800% 上限，依圖面長邊與 2 倍補繪所需精度計算安全範圍；一般 4096 像素長邊的圖面可達約 204,800%。這不是數學上的無限放大，極端倍率仍有繪圖引擎精度限制，達到時會顯示提醒。可直接輸入百分比（例如 `3200%`）並按 Enter；差異區域定位也不再受 800% 限制。高倍率仍只繪製可見圖塊，不產生整張巨型點陣圖。
10. v1.2.5 增加獨立比對視窗的「全螢幕看圖 · F11」：隱藏選檔、大標題、紀錄與底部滑桿，預設收合差異清單，僅保留精簡操作列與狀態列。全螢幕內可切換模式、直接輸入倍率、前後定位差異、展開清單；左右比較仍可拖曳圖中央分隔線。按 `Esc`／`F11` 或「離開全螢幕」還原原視窗；「檔案／紀錄」回到選檔及紀錄區。切換沿用同一張畫布及快取，不重新轉換 DWG；手動放大時保留倍率與圖面中心。
11. v1.2.6 將相鄰未快取圖塊合併繪製，減少每次縮放重複遍歷整份向量出圖的次數，再切回固定圖塊以保留平移快取。單批取樣限制在 400 萬像素，高品質補繪可在批次間取消；文字的原生解析度畫面先顯示，不再等 2 倍抗鋸齒完成。大型或非常密集的圖面仍會有短暫補繪時間，並非零延遲。

比較在本機透過已安裝的 **AutoCAD Core Console** 產生預覽，因此執行比較的電腦需要可正常啟用的 AutoCAD（目前以 AutoCAD 2024 驗證）。圖資不會上傳到其他服務。原始 DWG 以唯讀方式開啟，預覽在暫存工作目錄產生。

本版比較 **模型空間的 2D 俯視圖**，兩版使用相同世界座標範圍與比例。差異是線條影像的位置比較，**不是 CAD 圖元／屬性清單**，單純換線條顏色不列為位置變更。右側區域清單依 4096 像素寬的全圖預覽偵測，最多列出 200 區，超出會提醒且不隱藏圖面差異；極小變更請放大複核。放大後顯示會依向量圖重新比對可見線條。請選擇使用相同座標與單位的圖面；圖紙配置、不同原點或比例的圖面不會自動對齊。

請保留兩份要比較的 DWG：同步功能目前仍直接更新本機檔案，**沒有自動保存每次更新前的 DWG**。若圖面包含 XREF，會讀取各版當下能找到的參考檔；完整歷史版次需要連同當時的 XREF 一起保存，不能僅靠舊整合圖檔還原。

#### 比較功能測試（開發者）

`python -m unittest discover -s tests` 執行快速回歸測試，不連接 Google Drive。
另可執行 `python tests/test_dwg_preview_native.py`，使用本機 AutoCAD 產生測試 DWG，驗證兩版對齊及來源檔案未被修改；測試輸出保留在已忽略的 `.preview-test/`。

`python tests/create_architecture_demo.py` 會自行產生一組辦公室建築平面 DWG 新舊版，包含拆隔間、移門位、新增隔間，並產生紅／綠全圖、細節圖及比對結果 JSON；不使用真實專案圖資，也不連接已開啟的 AutoCAD 視窗。

`python tests/benchmark_comparison.py <comparison.json 路徑>` 可測量向量繪製、差異計算、操作快取縮放、高解析靜止畫面，以及分塊首次繪製／回訪／平移新增區域的耗時與命中數。這是處理時間，不含 Tk 顯示上傳，不等同實際螢幕 FPS。

`python tests/benchmark_zoom_latency.py <verification.json 路徑>` 可重用本機向量預覽，測量全螢幕不同倍率的首次繪製及原生繪製呼叫次數。`python tests/benchmark_zoom_ui.py <verification.json 路徑>` 另外測量縮放動畫至原生解析度文字顯示、以及最後抗鋸齒完成的時間；包括 Tk 畫面處理／影像上傳，但使用隱藏測試視窗，不代表實際螢幕 FPS。輸入使用 `verify_project_zoom.py` 產生的本機驗證記錄，不重新轉換或修改 DWG。

指定本機 JSON 工作階段（`old_dwg`、`new_dwg` 兩個 DWG 絕對路徑），可用編譯後的 exe 加上 `--compare-session <JSON 路徑>` 直接載入並比對。此模式不啟動同步、不讀寫登入與同步狀態；工作階段請保存在已忽略的 `.preview-test/`，不要把實際專案路徑提交到 GitHub。`python tests/verify_project_zoom.py <JSON 路徑>` 可唯讀驗證指定圖面的 800%／3200%／6400% 向量補繪與來源雜湊，結果只存於本機 `.preview-test/`。

可追加 `--fullscreen`，直接開啟全螢幕比對，例如 `雲端圖資同步工具_新版.exe --compare-session <JSON 路徑> --fullscreen`。轉換中仍可由精簡操作列取消，轉換提醒顯示於狀態列，詳細內容由「檔案／紀錄」查看。

## 第一步：設定 Google Cloud Console

### 1.1 建立 Google Cloud 專案

1. 開啟瀏覽器，前往 [Google Cloud Console](https://console.cloud.google.com/)
2. 使用您的 Google 帳號登入
3. 點擊上方的專案選擇器（可能顯示「選取專案」）
4. 點擊「**新增專案**」
5. 輸入專案名稱，例如：`DriveSync`
6. 點擊「**建立**」
7. 等待專案建立完成，然後選擇該專案

### 1.2 啟用 Google Drive API

1. 在左側選單，點擊「**API 和服務**」>「**程式庫**」
2. 在搜尋框輸入 `Google Drive API`
3. 點擊搜尋結果中的「**Google Drive API**」
4. 點擊「**啟用**」按鈕
5. 等待 API 啟用完成

### 1.3 設定 OAuth 同意畫面

1. 在左側選單，點擊「**API 和服務**」>「**OAuth 同意畫面**」
2. 選擇「**外部**」，然後點擊「**建立**」
3. 填寫必要資訊：
   - **應用程式名稱**：DriveSync（或您喜歡的名稱）
   - **使用者支援電子郵件**：選擇您的信箱
   - **開發人員聯絡資訊**：填入您的 Email
4. 點擊「**儲存並繼續**」
5. 在「範圍」頁面，直接點擊「**儲存並繼續**」
6. 在「測試使用者」頁面，點擊「**新增使用者**」，輸入您的 Google 帳號 Email
7. 點擊「**儲存並繼續**」
8. 點擊「**返回資訊主頁**」

### 1.4 建立 OAuth 2.0 憑證

1. 在左側選單，點擊「**API 和服務**」>「**憑證**」
2. 點擊上方的「**+ 建立憑證**」
3. 選擇「**OAuth 用戶端 ID**」
4. 應用程式類型選擇「**電腦版應用程式**」
5. 名稱填入：`DriveSync Desktop`
6. 點擊「**建立**」
7. 在彈出視窗中，點擊「**下載 JSON**」
8. **重要**：將下載的檔案重新命名為 `credentials.json`
9. 將 `credentials.json` 放到 `C:\Users\USER\Desktop\drive\` 資料夾中

## 常見問題

### Q: 開啟程式跳出「Failed to load Python DLL ...\Temp\_MEIxxxx\python314.dll」？
這是 v1.0.1 以前「單檔版」的問題：程式啟動需解壓到 Temp，容易被防毒軟體攔截。
**請下載 v1.0.2 以後的 MSI 重新安裝**（改為資料夾安裝，不再使用 Temp）。
若 v1.0.2+ 仍無法啟動：
1. 安裝 [Microsoft Visual C++ 2015-2022 可轉散發套件 (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe) 後重試
2. 確認 Windows 版本為 Windows 10 1809 以上或 Windows 11（按 Win+R 輸入 `winver` 查看）
3. 檢查防毒軟體的隔離區，將本程式加入排除清單

### Q: 如何監控其他資料夾？
在程式的「資料夾 ID」欄位貼上新的 Google Drive 資料夾連結或 ID 後按「立即同步」。
（資料夾 ID 可從 URL 取得：`https://drive.google.com/drive/folders/【這裡就是ID】`）

### Q: 從舊版（免安裝 exe）換到 MSI 安裝版，設定會保留嗎？
會。新版程式啟動時會自動把舊版放在 exe 旁邊的設定檔搬到 `%APPDATA%\雲端圖資同步工具`。
若你的舊 exe 放在別的資料夾且設定沒被帶過來，手動把舊 exe 旁的
`config.json`、`token.json`、`sync_state.json`、`sync_history.json`、`xref_flat_manifest.json`
複製到 `%APPDATA%\雲端圖資同步工具` 即可。
